# Windows-Begleitprogramm

Geplant: Autostart im Benutzerkonto, Symbol im Infobereich, Verbindungsstatus, Pi-Steuerbefehle und sichere Wiederverbindung. Die systemweite Abschaltsteuerung wird getrennt von der sichtbaren Oberfläche umgesetzt und vor Ort für Ausschalten und Neustart geprüft.
Das Windows-Tool erhält eine Medienverwaltung für das lokale Standardlogo bzw. die Standardanimation: Dateien importieren, Vorschau, aktivieren, zum Pi hochladen und nicht aktive Dateien entfernen. Unterstützte Formate und Prüfregeln stehen in [docs/media.md](../docs/media.md).
