# Pi-Anzeigeprogramm

Geplant: automatischer Vollbildstart auf dem Raspberry Pi 3 B+, Standardmedium ohne Windows-Verbindung, 800 × 480 Darstellung, Tippen zum Wechsel zwischen Marquee und Control-Panel-Bild, Erkennung von vier noch unbelegten Wischrichtungen sowie API für Status, Neuladen, Neustart und Herunterfahren.

Das aktive Standardbild, Video oder die Animation wird auf dem Pi persistent gespeichert und beim Start der Anzeige ohne Netzwerkverbindung geladen. Ein lokales Ersatzbild greift bei beschädigter Datei. Das Verhalten während der frühen Bootphase steht in [docs/media.md](../docs/media.md).

Die Gesten sind in [docs/touch.md](../docs/touch.md) beschrieben.
